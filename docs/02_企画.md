# 企画: ツギメモ

## 名前
- ツギメモ(英字 TsugiMemo、appId `jp.tsugimemo.app`)
- ストアの題: 「ツギメモ - ロック画面にメモ・ToDo」
- 同名の確認: iTunes Search API(日本)で「ツギメモ」「つぎメモ」を検索し、同名・含む名前は0件(docs/research/name_check.json、2026-10-09)。

## 一言の売り文句
済んだら消えて、次がロック画面に上がってくる。

## ひと目で分かる違い(1つだけ)
ロック画面のいちばん上は「いまの1行」だけを大きく。ロックしたまま丸を押すと、その行は消え、次の行が繰り上がる。
LockScreenNotes で出た「チェックしたものはロック画面から消えるようにして欲しい」(2026-10-02 のレビュー)と、Yondo の「ロック画面で完了できない」をそのまま形にしたもの。紹介動画は「丸を押す→次が上がる」の3秒で見せられる。

## 勝ち組から押さえる点
- 「メモしたのに、見ない」を最初の一文に(LockScreenNotes・Yondo と同じ悩み)。
- ロックしたまま済ませる(iOS 17 以降の押せるウィジェット / ライブアクティビティ、Android はホーム画面ウィジェットとお知らせのボタン)。
- 色を壁紙に合わせる(紙の色を選ぶ)。
- 設定の案内を絵つきで1画面ずつ(Yondo が一番褒められた点)。
- 登録なし・端末の中だけ。

## 不満のつぶし方
| 勝ち組への不満 | ツギメモ |
|---|---|
| ロック画面に出るタイミングが分からない | 書いた瞬間にウィジェットを更新。アプリの上に「いまロック画面に出ている1行」を常に見せる |
| オフにしても復活・勝手な通知・バイブ | 通知は出さない。ライブアクティビティは音もバイブも無しで、オフにしたら全部閉じる |
| 済んだ行が残って残りが見えにくい | 済んだ行はロック画面から消え、次が上がる。アプリでは「済んだ」にまとめて戻せる |
| 白紙で上書き・履歴が無い | 消した物・済んだ物は7日残し、1押しで戻す。上書き前の控えも保存 |
| デザインのたびに共有・レビューを強いる | させない。課金は買い切り1回だけ |
| 打ち直しで誤字る自動保存 | 入力は確定(改行・追加ボタン)で1行ずつ。打っている途中に保存しない |
| 報告先が TikTok だけ | 設定からメールで送れる |
| ホーム画面に置けない | ロック画面3種+ホーム画面の小・中 |
| 壁紙の作り直しが OS 更新で壊れる | 壁紙もショートカットも使わない |
| 4分割固定・長い文が入らない | 1行は60字まで。ウィジェットの大きさに合わせて行数が変わる |

## 無料でできること
- リスト1つ(名前は「いま」、行は何行でも)。
- ロック画面ウィジェット3種(四角・1行・丸)とホーム画面の小・中。ロックしたまま済ませる。
- iOS の「大きく出す」(ライブアクティビティ)、Android の「ロック画面にお知らせで出す」。
- 済んだ物・消した物を7日戻せる。
- 広告なし。

## ツギメモ+(買い切り)で開くこと
- リストを増やす(最大8つ。「買い物」「仕事」「持ち物」など)と、ロック画面に出すリストの切り替え。
- 毎朝もどすリスト(決めた時刻に済んだ印が外れる。朝の支度・薬以外の毎日の決まり事など)。
- 紙の色6色(無料は「生成り」と「墨」)。

## 値段
- ツギメモ+ 600円 買い切り(非消耗型)。月額は作らない(LockScreenNotes のレビュー「月額は嫌だが買い切りなら払う」)。
- RevenueCat: 商品ID `tsugimemo_plus`、entitlement `plus`、offering は current の1つ。キーは空で出荷し、空なら「購入は準備中です」と出す。

## ダウンロードが来る経路(推測)
- X と TikTok に「ロック画面で丸を押す→次の行が上がる」3秒の画面動画。勝った2本とも入口はここ。
- ストア検索の「ロック画面 メモ」「ロック画面 ToDo」。上位は勝ち組2本と古い大手。題に両方の語を入れる。
- 弱いところは正直に: 後追いの新顔はほぼ全部評価50件未満。違いの一言と動画が届かなければ同じ所で止まる。

## 作らないもの
- 手書き・写真の貼り付け・友だちと共有・サーバー・アカウント・広告。後追い組(LockNotes)は全部入れても伸びなかった。
