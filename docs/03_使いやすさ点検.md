# 使いやすさの自己点検(ルール「使いやすさ(徹底)」の各行)

確かめた画面写真: `scripts/e2e_out/<375|430>_<light|dark>/01〜16.png`(E2E が毎回撮り直す)

| ルール | どの画面で・どう満たしたか | 確かめ方 |
|---|---|---|
| 起動して3秒・ひと押しで本題 | 2回目以降は起動するとすぐ「いま」画面で、入力欄が下にある。初回も説明を「とばす」1押しで同じ所へ。説明の最後の「書きはじめる」を押すと、入力欄に文字を打てる状態(フォーカス済み)で始まる | E2E「書きはじめると、すぐ入力欄に文字を打てる」 |
| 最初の説明は3画面まで・飛ばせる | 3枚(見ない、をなくす / 丸を押すだけ / まず1行)。1・2枚目の右上に「とばす」 | E2E「最初の説明は飛ばせる」「3枚目で終わる」 |
| 1画面に主な操作は1つ | いま=1行足す(入力欄と朱の送るボタンだけが強い色)。ロック画面=置き方を見て、大きく出すをオン。設定=一覧から選ぶだけ | 画面写真 05・09・13 |
| よく押すボタンは下半分 | 入力欄・送る・「上に/下に」切り替えは下のタブのすぐ上に固定。シートの決定ボタンもシートの下。いまの1行の丸は上だが、ここはロック画面で押すのが本線(アプリ内は確認と修正) | 画面写真 05・07 |
| 空の状態に一文と次の一手 | 何も無い時「まだ何もありません/下の欄に1行書くと、こことロック画面のいちばん上に出ます。」。全部済んだ時「ぜんぶ済みました/次の1行を書いておくと、ロック画面で待っています。」。消したものが無い時も説明。ウィジェットも空なら「次の1行を書く」 | 画面写真 04、E2E「空の時は次の一手の説明が出る」 |
| 失敗に一文と次の一手 | 大きく出す・お知らせの許可を断られた時:「お知らせが許可されていません。設定アプリの『通知』で…オンにすると出せます。」+「もう一度ためす」。課金のキーが無い時:「購入は準備中です。もう少しお待ちを。」。ストアにつながらない時も一文。購入が見つからない時「戻せる購入は見つかりませんでした」 | 画面写真 11、E2E「断られた時の次の一手が出る」 |
| 初回 | 3枚の説明 → 入力欄が開いた状態。最初の画面は空の説明が出る | 画面写真 01〜04 |
| 文言は短く・話し言葉・「〜してください」の連打なし | 画面の文に「〜してください」は0か所(grep で確認)。ボタンは「書き直す」「いちばん上にする」「出す」「やめておく」など動詞1つ | `grep -r "ください" src/` = 0件 |
| 英語の取り残しゼロ | 画面の文字から英字2文字以上を探す検査を、説明・空・いま・ロック画面・課金の画面で毎回実行(iPhone / Android の名前だけ許可) | E2E「英語の取り残しが無い」 |
| 権限は使う直前に理由を一文 | 通知(Android)・ライブアクティビティ(iOS)は、ロック画面タブで「大きく出す」をオンにした瞬間にだけ、シートで理由を一文(「ロック画面に出すために、お知らせの許可を聞きます。音は鳴らしません。」)→「許可を聞く」。起動時には何も聞かない | 画面写真 10、E2E「許可の前に理由の一文が出る」 |
| 片手・小さい画面(375)・大きい文字 | 375 幅と 430 幅の両方で全画面を回し、横はみ出し無しを検査。文字を1.35倍(21.6px 基準)にしても崩れない。iOS は端末の文字の大きさ設定に合わせる(-apple-system-body) | E2E「横にはみ出さない(大きい文字)」、画面写真 16 |
| 押せる所は 44pt 以上・戻る・セーフエリア | 丸・タブ・送る・閉じるは 44px 以上の当たり。シートは背景タップ・×・Esc で閉じる。上下は env(safe-area-inset) で逃がす | CSS `--hit: 44px` |
| 触った時の小さな振動 | 足す・タブ・選ぶは軽く、済ませる・購入は少し強く(@capacitor/haptics) | src/platform/native.ts |
| 取り消せる | 済ませた・消した直後に「戻す」。済んだ行は「済んだ」から1押しで戻る。消した行は設定「消したもの」に7日 | E2E「戻すと元に戻る」「戻すと消したものから消える」 |
