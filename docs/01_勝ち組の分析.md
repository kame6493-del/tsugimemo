### 選ばれた理由(レビューと X の声から)
- 「メモしたのに見ない」をそのまま言い当てた。LockScreenNotes の説明文の1行目と、Yondo の星5レビュー「メモしてもそれを忘れるなんてことが多々あって」が同じ悩み。
- 設定がこわくない。Yondo は「ショートカットまで誘導してくれてとてもわかりやすい」「説明書がわかりやすすぎて感動したの人生初めて」(2026-09-20)。LockScreenNotes も「チュートリアルも分かりやすく、すぐに導入できました」(2026-09-05)。
- 自分の壁紙になじむ見た目を選べる。LockScreenNotes「デザインも自分でカスタマイズできて壁紙に馴染む」(07-19)、Yondo「カラーや大きさ、分割デザインも自分仕様に」(07-29)。
- ロックしたままチェックできる(LockScreenNotes)。「チェックボックスの機能もあるからタスクとか…めちゃくちゃ便利」(07-09)。
- 広がり方は動画と X。LockScreenNotes は「Xでバズっていてすぐにインストール」(07-13)・「SNSで見かけて」(10-02)、Yondo は「TikTokの紹介動画から」(07-21, 07-27)・「Xで話題になっているのを見かけて」(09-03)。X でも「まじでみんなこのアプリ使って欲しい」(2026-09-12)。
- 手で書いた物が届く温かさ(Chalkee)。「ホーム画面開くと友達からのイラストが見れて嬉しい」(06-25)。

### 不満(全部つぶす対象)
LockScreenNotes
- 書いたメモがロック画面に出るタイミングが分からない。出たり出なかったり(07-23)。
- 表示をオフにしても時間がたつと復活する。通知の形で出てくる(09-05)。望まないタイミングでメモの通知が届く(10-02)。
- バイブが鳴る(07-13)。他のアプリを使っている時に上の黒い部分に触るとこのアプリに飛ぶ(07-19)。
- デザインを替えるたびに「共有・フォロー・レビュー」をさせられる。「月額は嫌だが買い切りなら払う」(07-25、英語レビュー)。
- チェックした行がロック画面に残り、残りが見えにくい。「チェックしたものはロック画面からは消えるようにして欲しい」(10-02)。
- 入力の保存が早すぎて打ち直しで誤字る。チェックの前に文字が入る(10-02)。
- 突然チュートリアルに飛ばされ、メモが白紙で保存された。履歴が無く戻せない(07-30)。
- 不具合の報告先が TikTok だけ(09-05, 09-10)。
- ホーム画面のウィジェットとして置けない(X 2026-09-20)。

Yondo
- ロック画面の表が自動で新しくならず、毎回設定し直す(07-29)。ショートカットが動かない(iPhone 17 / iOS 26.6、08-07)。iOS 27 でショートカットの画面が変わり設定ガイドを作り直し中(作者の X、2026-09-15)。= 壁紙を作り直す方式は OS の変更に弱い。
- ロック画面ではタスクを完了できない(07-30, 08-08)。
- 4分割に固定で、1つ・2つにできない。長い文が入らない(07-17, 07-27, 08-15)。

Chalkee
- 無料だと1日の送信数が少ない。広告を見ないと送れない(08-07, 08-29)。
- 最新のメッセージが出ない・タップで開けない(03-23)。

### 勝ち負けを分けた点(推測を含む。根拠は上の数字)
1. 早さと動画。勝った2本は「ロック画面にメモ」という見せ方が新しかった時期(5月・6月)に出て、X と TikTok で動く画面が回った。8月以降の後追いは、機能が多くても(LockNotes は手書き・共有・150種の紙)評価52件で止まった。機能の数では勝てない。
2. 一言で何が違うか言えるか。LockScreenNotes は「大きく」、Yondo は「4つに仕分けて全部見える」、Chalkee は「手書きが届く」。負けた側は「ロック画面にメモ」以上の一言が無い(ロックメモ・LockScreenMemo・即メモ)、または量産の見た目違い(待受にメモ帳シリーズ)。
3. 設定の案内の手厚さ。Yondo の星5の多くが「設定ガイドが分かりやすい」。逆に壁紙・ショートカット方式は OS 更新で壊れ、星2が付いている。
4. 見た目を自分の壁紙に合わせられること。勝った2本とも、色・文字・大きさを替えられることがレビューで褒められている。
5. 2022年からある「ロック画面ウィジェットだけ」のアプリは伸びていない。ウィジェットの小さな枠に文字を出すだけでは目新しさにならない。ここは自分も同じ形になりうる弱点で、企画で必ず手当てする(→ 02_企画.md)。

## 3. 企画に持ち込むこと
- 押さえる: 「メモしたのに見ない」の一言、ロックしたまま済ませる、壁紙になじむ色、迷わない設定案内、すぐ使える(登録なし・端末の中だけ)。
- つぶす: 出たり出なかったり(→ 書いた瞬間に更新するウィジェットを主にし、何が今出ているかを画面の上に常に見せる)、勝手な通知・バイブ(→ 出さない)、済んだ行が残る(→ 消えて次が上がる)、白紙で上書き(→ 消した物は7日残す)、課金の代わりにSNS行動を強いる(→ 買い切り1回だけ)、報告先が TikTok だけ(→ アプリ内からメール)、ホーム画面に置けない(→ ホームの小・中も)、OS 更新で壊れる壁紙作り直し(→ 使わない)。
- 小さいウィジェットだけでは負ける(上の5)ので、「ひと目で分かる違い」を1つ持つ: 済んだら消えて、次の1行がロック画面に上がってくる。
